# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short, we are committed to a welcoming, harassment-free experience for everyone. Be respectful, assume good intent, and give constructive feedback.

Report unacceptable behaviour privately to the maintainers through GitHub. All reports will be reviewed and handled confidentially.

Participants in the *Inside the Game: Developer Hackathon* are also bound by the event's own Code of Conduct and rules.

Trust by design

  • Synthetic data only: fictional clubs, players and matches
  • Fan text is only ever a user message, never a prompt
  • Agents' tools are read-only, except the Director's cue tools, which follow scheduler rules
  • Goals and red cards never wait for an agent
  • Unverifiable answers become an honest "couldn't verify"
  • Rate limits, CORS allow-list, gitleaks in CI

# Responsible AI

PitchLens uses AI agents to explain football and personalise it for fans. This note covers what the AI
does, the risks we designed for, and how each one is controlled. It follows Microsoft's Responsible AI
principles: fairness, reliability and safety, privacy and security, inclusiveness, transparency and
accountability.

## What the AI does, and what it does not

- **Facts first, words second.** Every number (xG, win probability, speeds, pass difficulty, pressing) is
  computed by deterministic, tested code. Models only put those facts into words, answer questions with
  tools over them, and curate what goes on air. They never compute a statistic.
- **The live pipeline does not depend on AI.** Insights, template commentary in six languages and overlay
  cues are produced without a model in under 300 ms. If every model is unavailable, the product still
  works: fans see template text, the fact recap and rules-based overlays.
- **Synthetic data only.** All clubs, players and matches are fictional and generated by our simulator.
  No real Premier League data, names or likenesses are used.

## Risks and controls

| Risk | Control | Measured |
|---|---|---|
| **Hallucinated numbers or facts** | Every number an agent states must appear in a tool result (rules check); a Fact-Checker agent then judges whether each claim follows from the facts (approve, revise, reject). Narration has its own grounding validator with template fallback. | Fact-Checker: 50/50 seeded errors caught, 0/50 correct drafts rejected ([eval.md](eval.md)) |
| **Wrong answers presented as certain** | Unverifiable answers become an honest "couldn't verify" message; approved answers carry a "verified" mark and a "how we answered" trace | Ask the Match: 26/30 on the eval, no failed case stated a wrong number |
| **Harmful content in or out** | Azure AI Content Safety (hate, sexual, violence, self-harm, Prompt Shields) plus a local screen, on fan questions, display names, answers, recaps and tactical notes | Unit tests with football phrasing that must pass and harmful phrasing that must not |
| **Prompt injection** | Fan text is only ever a user message; Prompt Shields and the local screen block injection attempts before any model sees them; agents have no write tools except the Director's cue tools, bounded by scheduler rules | Eval guard cases: 3/3 |
| **Over-automation in broadcast** | The Director proposes and a human producer approves in `/studio` (approve mode); goals and red cards never wait for an agent; stale stories expire instead of airing late | Director eval: within the rate limit, no goal delayed |
| **Cost and availability** | Per-client rate limits and per-match and daily agent token caps; agents stand down over a cap | Unit tests |
| **Unequal quality across languages** | Six languages from day one, with native template packs, glossaries and RTL support for Arabic; names stay in Latin script so they can be checked; non-English rewrites are number-checked and judged against the verified English text, falling back to it if they fail | Live checks in Spanish, Hindi and Arabic ([agents.md](agents.md)) |

## Transparency

- AI-written text is labelled in the product ("AI" badges on narration, "verified" on answers, the
  author `agent:analyst` on tactical notes).
- `/studio` shows an **Agent Trace**: every agent step, tool call and Fact-Checker verdict.
- The evaluation method, results and known weaknesses are published in [eval.md](eval.md), including
  runs that went wrong and what we changed.

## Privacy

Fan profiles are anonymous: a persona, a language, favourite clubs and players, and an optional display
name (screened by content safety). There are no accounts, no personal data and no tracking of individuals.
Questions are processed to answer them and kept only in a short in-memory trace for the studio.

## Known limitations

- The judge can accept a false "the data does not show X" claim (see [eval.md](eval.md)).
- The local safety screen is a fallback with deliberately narrow patterns; hate and sexual content need
  Azure AI Content Safety, which the deployment enables.
- Evaluation so far ran on Groq's free tier (`gpt-oss-120b`); it will be repeated on Microsoft Foundry.

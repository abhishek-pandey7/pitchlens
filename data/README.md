# Data

Everything here is **synthetic**. No real Premier League data, clubs or players.

- `rosters/league.json`: the fictional 20-club league (generated by `python -m pitchlens.sim.rosters`)
- `samples/`: the five storyline matches, committed (events gzipped)
- `matches/`: the full 50-match dataset, generated locally with `python -m pitchlens.sim.cli dataset --count 50` (git-ignored)

The format, conventions, calibration and limitations are documented in [docs/dataset.md](../docs/dataset.md). Data is licensed [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
